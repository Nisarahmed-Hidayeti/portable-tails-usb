Today I installed CachyOS on a 32 GB USB drive, which means I can now carry my entire operating system in my pocket.

## How I did it

I used two USB drives:

16 GB USB → CachyOS installer
32 GB USB → The actual CachyOS system
1. Created the CachyOS installer

First, I downloaded the CachyOS ISO from the official CachyOS website and put it on the 16 GB USB.

2. Booted the installer

I plugged both USB drives into my PC and booted into the CachyOS installer from the 16 GB USB.

3. Installed CachyOS onto the 32 GB USB

I selected the 32 GB USB as the installation drive and installed CachyOS onto it.

After the installation finished, I could boot directly from the 32 GB USB.

The result

Now I have a portable CachyOS installation that I can carry around with me.
Instead of just having a USB that boots an installer or live environment, I have an actual Linux system with my own files, programs, settings, and desktop environment.
My operating system is literally in my pocket. 🐧💾
